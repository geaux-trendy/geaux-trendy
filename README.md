# Geaux Trendy homepage

This is a responsive, static preview homepage for Geaux Trendy. It contains `index.html`, `styles.css`, `script.js`, and the `assets/` folder. Keep all of these together in the root of your GitHub repository.

## Deploy on Vercel

1. In Vercel, select **Add New → Project** and import your GitHub repository.
2. Set **Framework Preset** to **Other** (plain HTML/CSS/JS).
3. Leave **Build Command** empty and **Output Directory** empty/default.
4. Click **Deploy**.
5. Once the deployment works, go to **Project Settings → Domains** and add `geauxtrendy.com`. Follow Vercel's exact DNS instructions at your domain registrar.

## Important

This is a **design preview**. Product categories, favorites, search, seller registration, checkout, subscriptions, and payments are not yet functional. The seller-interest link uses `hello@geauxtrendy.com` as a placeholder: replace it with an address you actually control before publishing. Do not collect payments or promise a live checkout until those services are built and tested.

The generated photos are illustrative assets, not real seller listings.
